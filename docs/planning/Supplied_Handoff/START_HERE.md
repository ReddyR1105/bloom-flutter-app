# Start here — Bloom handoff for VS Code Codex

This ZIP is a **Codex handoff pack**, not a complete app, APK, signed proposal, or final iCollege submission.

1. Extract this ZIP in a fresh local workspace, e.g. `D:\\Bloom`.
2. Open the extracted folder in VS Code, launch Codex (Agent mode), and paste the **entire contents** of `agent/BLOOM_CODEX_MASTER_PROMPT.md` into Codex chat. Attach/refer to the docs and design files if necessary.
3. Codex must ask for proof of instructor-team approval before writing Flutter implementation. The proposal is dated Oct 18 and notes that the Oct 17 deadline has passed; coordinate late proposal approval with the instructor.
4. Fill in actual team members, GitHub/ClickUp URLs, genuine screenshots and signatures. Do not fabricate required evidence.
5. Once approved, Codex can build the project on a Windows machine with Flutter/Android SDK installed; the team must still provide human evidence, complete the recording and submit via iCollege.
